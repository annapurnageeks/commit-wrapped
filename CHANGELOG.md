# Changelog

## 0.1.0 (2026-11-23)

First release.

- Finds every git repo in the folders you give it and keeps your commits from the year
- 15 animated slides: commits, lines, months, a 24-hour clock, weekdays, streaks, a calendar, languages, top files and repos, biggest commit, commit messages and a coding personality
- A 1080×1920 share card with Save image, Copy text and Post on X
- `--everyone` for a project's year, `--private` for closed-source work
- `--brief` and `--script` so an AI agent can write personal captions; works as a Claude Code skill
